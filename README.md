🔊 Text-to-Speech Converter

A simple and interactive Text-to-Speech web application that converts user input into spoken audio using the Web Speech API. Built with pure frontend technologies, this project demonstrates real-time speech synthesis, DOM manipulation, and modern UI design.

-------------------------------------------------------

🚀 Features

Convert written text into natural voice output

Uses browser-based Web Speech API (no backend required)

Adjustable speech properties (rate, pitch, volume)

Clean, responsive user interface

Handles empty input gracefully

Lightweight and fast

----------------------------------------------------

🛠 Tech Stack

HTML

CSS

JavaScript

Web Speech API

-------------------------------------------------

📚 What I Learned

Working with browser-native APIs

Event-driven JavaScript programming

DOM manipulation

Frontend project structuring

Accessibility-focused development
